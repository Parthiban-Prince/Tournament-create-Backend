# 🏆 Tournament Create – Backend System

## 📌 Project Overview
**Tournament Create** is a fully functional backend application built using **Node.js** and **MongoDB** for managing sports tournaments.  
It provides secure **JWT-based authentication**, **role-based access control (User & Admin)**, and complete workflows for **users, teams, tournaments, and matches**.

This backend is suitable for sports tournament platforms where users can create and manage teams, while administrators control tournaments and match scheduling.

---

## ⚙️ Technology Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT (JSON Web Token)  
- **Image Upload:** Multer / Cloud storage support  
- **Security:** Password hashing, token validation  
- **Architecture:** RESTful API  

---

## 👤 User Features
- User **Sign Up & Sign In**
- Secure **JWT token generation**
- View, edit, and update user profile
- Upload profile images
- Create a team
- Join a team
- Leave a team
- View tournaments and match details

---

## 🛡️ Admin Panel Features
- Admin login using **default credentials stored in MongoDB**
- Password matching and validation for admin login
- Create tournaments
- Fix matches between two teams
- Update match status:
  - **Upcoming**
  - **Completed**
- View dashboard statistics:
  - Total users
  - Total tournaments
  - Registered teams
- Delete teams when required
- Full control over tournament and match management

---

## 🏟️ Tournament & Match Management
- Admin creates tournaments
- Teams register for tournaments
- Matches are fixed between teams
- Match status and results can be updated
- Users can view upcoming and completed matches

---

## 🔐 Authentication & Security
- JWT-based authentication for users

- Secure admin login validation

## 📦 API Capabilities
